# ✋ Hand Gesture Recognition using Machine Learning

## 📌 Project Overview
This project focuses on recognizing hand gestures using Machine Learning techniques. The model learns from hand gesture images and predicts the corresponding gesture class.

This project was completed as Task 04 of my Machine Learning Internship at Prodigy InfoTech.

## 🎯 Objectives
- Load and explore the hand gesture image dataset.
- Preprocess images for model training.
- Train a Machine Learning model to recognize hand gestures.
- Evaluate model performance using test images.
- Predict gesture classes and display prediction confidence.

## 🛠️ Technologies Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Machine Learning

## 📂 Project Files
- `Task_04_Hand_Gesture_Recognition_ML.ipynb` — Notebook containing the implementation, model evaluation, and gesture predictions.

## 🔍 Project Workflow
1. Dataset loading and exploration.
2. Image preprocessing.
3. Feature preparation and model training.
4. Model evaluation.
5. Hand gesture prediction on sample images.
6. Displaying actual gesture, predicted gesture, and prediction confidence.

## 📊 Results
The trained model was tested on sample hand gesture images. The notebook displays the actual gesture class, predicted gesture class, and prediction confidence.

## 🚀 Key Learnings
- Image-based Machine Learning.
- Data preprocessing and model training.
- Hand gesture classification.
- Model evaluation and prediction visualization.
